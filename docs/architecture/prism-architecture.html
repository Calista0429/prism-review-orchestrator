PRISM Architecture

Implemented local demo · bounded model assessment, deterministic routing, durable history

Bounded model responsibility

  • • Jev returns five scores, confidence and probabilities.
  • • The adapter validates output and normalizes 0–4 to 0–10.
  • • Failure routes to triage; no silent demo fallback.
  • • The API key is read only by the server.

Policy-driven review

  • • TypeScript rules combine scores, evidence and policy.
  • • CI, sensitive paths and ownership constrain routing.
  • • Simulation replays stored scores without model calls.
  • • Reviewer suggestions do not create assignments.

Transactional history

  • • Assessments, scores, decisions and audit commit together.
  • • Idempotency stores the response in that transaction.
  • • Overrides append decisions without erasing history.
  • • PGlite and PostgreSQL use the same schema and queries.
